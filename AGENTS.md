# COPY THAT? Project Rules

- Core thesis: "Communication is the control system."
- Timing will eventually be the primary gameplay mechanic.
- Deterministic outcomes are preferred over random failure.
- The human is the game director/designer.
- Codex is the engineering partner.
- Do not introduce new features unless specifically requested.
- Browser stability and playability are higher priority than realism.
- Three.js + TypeScript + Vite is the fixed stack unless explicitly changed.
